features:
  - title: Write for users
    details: Sacho never turns commit messages into changelog prose. You decide what changed for users and say it in their language.
  - title: Keep notes with the code
    details: Each unreleased entry follows its change through merges, rebases, cherry-picks, and reverts without everyone editing the same changelog section.
  - title: Catch omissions before release
    details: Hooks and CI find missing entries, invalid fragments, and generated changelogs that have fallen out of sync.
  - title: Use it in any repository
    details: Sacho is a single binary with no runtime dependency. It works across language ecosystems and supports Git, Jujutsu, and Mercurial.
